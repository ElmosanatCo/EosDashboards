# Shared Project Resources

This directory is the authoritative source for reusable EosDashboards visual and document assets.

## Structure

- `branding/`: approved company logos and identity assets, including light, dark, color, and monochrome variants when supplied.
- `fonts/`: self-hosted web fonts. Vazirmatn is the approved primary typeface.
- `icons/`: custom icons not supplied by the approved UI component system.
- `images/`: reusable optimized images.
- `templates/`: approved printable and document templates.

## Asset record

For every added asset, record its source, owner, license, version or acquisition date, permitted uses, and optimization notes in this file or an adjacent metadata file. Do not add confidential assets or files without redistribution permission.
